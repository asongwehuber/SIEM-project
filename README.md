# SIEM Project

A modular Security Information and Event Management system.

## Components

### Mini-SIEM
Main SIEM platform responsible for:

- Log ingestion
- Log storage
- Threat detection
- Alert generation
- Automated response
- Dashboard visualization

### SIEM Agent

Secure intermediary between log sources and Mini-SIEM.

Responsibilities:

- Log verification
- Signature validation
- Replay attack protection
- Log normalization
- Secure forwarding

### Log Generator

Simulation framework for generating security events:

- Linux authentication logs
- Windows security events
- Firewall events
- Apache access logs
- MySQL security logs
